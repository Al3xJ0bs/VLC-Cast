# VLC Cast

Android-приложение: поделиться видео или музыкой из любого приложения — и оно играет во VLC на Apple TV.

Прямой каст видео через AirPlay на tvOS 27.2 не работает (ТВ отклоняет любую вставку в очередь — подробнее в [исследовании](research/direct-cast-research-2026-11-10.md)), поэтому VLC Cast идёт другим путём: находит прямую ссылку на видео и запускает её во VLC через протокол Companion (тот же, что использует пульт Apple TV). Видео играет на ТВ, телефон при этом свободен.

Текущая версия: **0.9.3.6** (versionCode 39). История изменений — в [CHANGELOG.md](CHANGELOG.md).

## Возможности

- **Видео из любого приложения.** Поделиться ссылкой из Chrome, YouTube, Telegram, Instagram, галереи — приложение само найдёт поток (HLS `.m3u8`, MP4, DASH) и запустит его во VLC на ТВ. Приложение при шаринге не открывается: всё происходит в фоне, на экране только уведомление.
- **Авто-детект плееров.** Перехват сетевых запросов и JS-скан страницы: Kodik, Alloha, YouTube (InnerTube), VK Video, Sibnet, OK.ru, HDRezka, Aniboom и другие плееры; JSON-LD VideoObject и oEmbed. Если видео не нашлось само за 30 секунд — открывается видимый браузер, где можно нажать ▶ в плеере.
- **Локальные файлы.** Видеофайл из Telegram или галереи кастится через локальный HTTP-сервер на телефоне; временная копия автоматически удаляется после каста.
- **Музыка.** SoundCloud, YouTube Music, интернет-радио, Bandcamp, прямые ссылки на аудио и локальные аудиофайлы. Spotify и Apple Music не поддерживаются — их потоки зашифрованы (DRM).
- **Субтитры.** Дорожки из потока, плюс внешние субтитры из OpenSubtitles.
- **Авто-следующая серия.** По таймеру длительности следующая серия запускается сама; предзагрузка следующей серии в фоне.
- **Продолжить с того же места.** Resume для HLS-потоков (для MP4 недоступно).
- **Плейлисты YouTube.** Первая серия кастится, остальные — в очередь.
- **Пробуждение ТВ.** Спящий Apple TV будится Wake-on-LAN (magic packet по MAC из ARP-кэша), затем Companion `turn_on`.
- **Надёжность.** Авто-ретрай по кандидатам с pre-flight проверкой, проба скорости зеркал, выбор 60fps при равном качестве, проверка установки VLC на ТВ до запуска, запоминание озвучки и выбора субтитров, очередь шарингов, самопроверка при запуске, карточка «Что нового» после обновления.
- **Самообновление.** Проверка обновлений при запуске; новая версия скачивается и устанавливается внутри приложения.

## Требования

- Apple TV с установленным **VLC** (из App Store на ТВ).
- Телефон и Apple TV в одной домашней Wi-Fi сети.
- Android 8.0+ (minSdk 26). Интерфейс на русском.

При первом запуске: найти Apple TV, ввести PIN с экрана ТВ один раз. Спаривание (Companion и HAP) сохраняется между обновлениями — повторный PIN не нужен.

## Установка

Скачать APK из [Releases](https://github.com/Al3xJ0bs/VLC-Cast/releases) и установить поверх предыдущей версии. Обновления приходят сами: приложение проверяет `latest.json` в репозитории при запуске и предлагает «Скачать и установить», когда есть новая версия.

## Как пользоваться

1. Открыть страницу с видео в браузере или любом приложении.
2. Меню → «Поделиться» → «VLC Cast».
3. Видео само запустится во VLC на Apple TV.

Ничего больше нажимать не нужно. Если видео не нашлось автоматически — через 30 секунд появится видимый браузер: нажмите ▶ в плеере, ссылка перехватится и видео запустится.

## Приватность

Приложение ничего никуда не отправляет: нет аналитики, аккаунтов и серверов. Видео ищется и запускается локально; локальный прокси на телефоне только добавляет Referer/куки для потоков, которые их требуют. Данные спаривания хранятся в AndroidKeyStore и SharedPreferences на телефоне.

## Сборка из исходников

Без Gradle: aapt2 + kotlinc + d8 + zipalign + apksigner. Тулчейн: JDK 11, kotlinc 1.4.31, Android SDK build-tools 34.0.0, платформа android-34.

```sh
./build.sh   # → VLC-Cast-<версия>.apk (тестовый ключ подписи)
```

Тесты:

```sh
tests/run_tests.sh        # unit-тесты (JVM)
tests/run_mock_test.sh    # Companion-клиент против mock Apple TV (Python)
```

Мок доказывает корректность фрейминга протокола, а не то, что реальный ТВ примет запуск — живой тест возможен только на настоящем Apple TV.

## Честные ограничения

- **Прямой каст мёртв на tvOS 27.2** и удалён из приложения в v0.5.2: `POST /play` возвращает 200, но ТВ никогда не запрашивает медиа; `POST /command insertPlayQueueItem` — HTTP 400 во всех формах. Рабочий путь — только VLC через Companion.
- **Без DRM.** Защищённый контент (Widevine/FairPlay, Spotify, Apple Music) не поддерживается.
- **Ссылки плееров живут часы.** Извлечённая ссылка устаревает; при ошибке каста откройте страницу заново.
- **Resume — только для HLS.** Для MP4 продолжение с того же места недоступно.
- **Длительность серии — по таймеру.** Companion не отдаёт состояние воспроизведения, поэтому конец серии определяется по длительности потока; пауза и перемотка с пульта таймер сбивают.
- **Подпись — тестовый ключ** (`build/aircast.keystore`). Для публикации в магазине нужен свой релизный ключ.
- **targetSdk 34.** Поднять до 35/36 при наличии соответствующего SDK.
